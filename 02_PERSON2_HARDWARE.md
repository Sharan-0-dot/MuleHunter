## 1. Your scope

You own the **Raspberry Pi "Compliance Desk" (Alert Box)**:
- **Raspberry Pi 3B+ (1GB RAM)** with USB mic, speaker (3.5mm or USB), piezo buzzer, Red / Yellow / Green LEDs + resistors, and joystick push-button.
- Receives real-time streaming alerts from the laptop backend over WebSocket `/ws/pi`.
- Shows risk severity level on the LEDs (Green = low, Yellow = medium, Red = high).
- Buzzes the piezo buzzer to alert the compliance officer.
- Downloads the AI/TTS explanation audio (`.wav`) generated by the backend.
- Listens for up to 25 seconds for the spoken keyword **"explain"** (via Vosk offline speech recognizer) OR a joystick push-button press.
- Plays the summary `.wav` through the speaker.
- Sends cryptographically HMAC-SHA256 signed acknowledgements back to `POST /api/pi/ack`.
- Handles `clear` signals when the officer freezes the cluster on the dashboard (turns off LEDs/buzzer immediately).

## 2. Hardware Wiring (Raspberry Pi 3B+ BCM Pins)

| Part | Pi Pin (BCM) | Physical Pin | Notes |
|---|---|---|---|
| **Green LED** | GPIO17 | Pin 11 | 220–330 Ω resistor in series, other leg to GND |
| **Yellow LED** | GPIO27 | Pin 13 | 220–330 Ω resistor in series, other leg to GND |
| **Red LED** | GPIO22 | Pin 15 | 220–330 Ω resistor in series, other leg to GND |
| **Piezo Buzzer** | GPIO18 | Pin 12 | Active (HIGH/LOW) or Passive (PWM via `gpiozero.PWMOutputDevice` / `TonalBuzzer`) |
| **Joystick Button (SW)** | GPIO23 | Pin 16 | Other leg to GND, configure with internal pull-up (`Button(23, pull_up=True)`) |
| **Ground (GND)** | GND | Pin 6, 9, 14, 20, 25, 30, 34, or 39 | Common ground rail on breadboard |
| **USB Mic** | USB port | Any USB | Test with `arecord -l` |
| **Speaker** | 3.5mm or USB | Audio jack / USB | Test with `aplay` |

### Alert Level Behaviour:
- **`green`**: Green LED on, 1 short beep.
- **`yellow`**: Yellow LED on, 2 beeps.
- **`red`**: Red LED on, pulsing buzzer alert pattern.
- **`escalate`**: LED blinks rapidly (officer took longer than window).
- **`clear`**: Turn off all LEDs and silence buzzer immediately (officer froze cluster).

## 4. Pi Client Service Architecture (`pi/main.py`)

### 4.1 Configuration
```python
BACKEND_URL = "http://<LAPTOP_IP>:8000"
WS_URL = "ws://<LAPTOP_IP>:8000/ws/pi"
SHARED_SECRET = "mulehunter-demo-secret"
VOSK_MODEL_PATH = "/home/pi/vosk-model"
KEYWORD = "explain"
LISTEN_SECONDS = 25
```

### 4.2 State Machine
`IDLE` ➔ `ALERTING` (LED/buzzer on, download wav, ack `received`) ➔ `LISTENING` (Vosk mic + joystick) ➔ `PLAYING` (aplay wav, ack `played`) ➔ `DONE` (await `clear`)

### 4.3 WebSocket Client (`/ws/pi`)
Connect to `ws://<LAPTOP_IP>:8000/ws/pi`. Auto-reconnect with 2s backoff on disconnect.
- On `{"type": "alert", ...}`:
  1. Download `.wav` from `wav_url` to `~/cache/{cluster_id}.wav`.
  2. Set LED (Green/Yellow/Red) and sound buzzer.
  3. Send HMAC-signed ack `received`.
  4. Start 25s listening loop for "explain" or joystick press.
- On `{"type": "clear", ...}`:
  Turn off all LEDs, silence buzzer, reset to IDLE.
- On `{"type": "escalate", ...}`:
  Blink LED rapidly.
- On `{"type": "ping"}`:
  Reply `{"type": "pong"}`.

### 4.4 Keyword Listener (Vosk) & Joystick Fallback
- Open 16 kHz mono raw stream with `sounddevice.RawInputStream`.
- Feed `KaldiRecognizer(model, 16000, '["explain", "[unk]"]')`.
- If recognized word contains `"explain"`:
  Send HMAC-signed ack `explain_voice` ➔ play `.wav` using `aplay`.
- If joystick button (GPIO23) pressed during window:
  Send HMAC-signed ack `explain_joystick` ➔ play `.wav` using `aplay`.
- If 25 seconds elapse with no input:
  Send HMAC-signed ack `timeout`. Keep LED lit.

### 4.5 HMAC Acknowledgement Helper
Send HMAC-SHA256 signature in `X-Signature` header:
```python
import hmac, hashlib, json, requests

def send_ack(alert_id, event):
    payload = {
        "alert_id": alert_id,
        "event": event,
        "ts": datetime.now(timezone.utc).isoformat()
    }
    body_bytes = json.dumps(payload).encode("utf-8")
    sig = hmac.new(SHARED_SECRET.encode("utf-8"), body_bytes, hashlib.sha256).hexdigest()
    headers = {"X-Signature": sig, "Content-Type": "application/json"}
    try:
        requests.post(f"{BACKEND_URL}/api/pi/ack", data=body_bytes, headers=headers, timeout=3.0)
    except Exception as e:
        print(f"Ack failed: {e}")
```

### 4.6 Auto-start on boot (`systemd`)
Create `/etc/systemd/system/mh-pi.service`:
```ini
[Unit]
Description=Mule Hunter Raspberry Pi Desk Service
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi
ExecStart=/home/pi/mh/bin/python3 /home/pi/pi/main.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```
Enable and start:
```bash
sudo systemctl daemon-reload
sudo systemctl enable mh-pi.service
sudo systemctl start mh-pi.service
```
